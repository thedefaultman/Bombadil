> **Verified:** 2026-11-12 against `main` at `7d37bc5`. On 2026-11-13 every row that changed since `7d17600` was read again, with its anchors, in the code, and ten rows that did not change were read again as well. Run on that day, on made-up folders and diagrams: `launcher.match` (the launcher rows marked Reproduced), `desk.asked_for_desk` and `Desk.apply`, `sysmap` and `cards.validate_diagram`; the rows for coding sessions and the Brain's session lookup were read and not run, and nothing that needs PySide6, QEMU, Docker or a running Hyprland was run

This file lists the defects and gaps that are still true on `main`, so a contributor knows what is rough before building on it. Every row was checked against the code at the commit above, and only what is still true is listed; what has been fixed is not. Line numbers refer to that commit and move as the code changes; search for the named function, command or file if a line has shifted. Where the page that owns a piece lists the same gap in more detail, the row links to it.
