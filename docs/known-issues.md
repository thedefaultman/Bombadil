> **Code:** `src/bombadil/agentd.py`, `src/bombadil/launcher.py`, `src/bombadil/dev.py`, `src/bombadil/desk.py`, `src/bombadil/providers.py`, `src/bombadil/snapshots.py`, `src/bombadil/config.py`, `src/bombadil/hypr.py`, `src/bombadil/mcp_server.py`, `src/bombadil/notifications.py`, `src/bombadil/outbox.py`, `src/bombadil/mail/tools.py`, `src/bombadil/connect/`, `src/bombadil/brain/`, `bin/`, `shell/`, `share/qml/Bombadil/`, `iso/airootfs/usr/local/bin/`, `iso/airootfs/etc/systemd/`, `scripts/`, `tests/`
> **Verified:** 2026-11-09 against `main` at `7d17600`

This file lists the defects and gaps that are still true on `main`, so a contributor knows what is rough before building on it. Every row was checked against the code at the commit above, and only what is still true is listed; what has been fixed is not. Line numbers refer to that commit and move as the code changes; search for the named function, command or file if a line has shifted. Where the page that owns a piece lists the same gap in more detail, the row links to it.
