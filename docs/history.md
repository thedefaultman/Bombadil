  - `bombadil-agentd` and `bombadil-shell` are systemd user services next to a drop-in that restarts `mako` (`iso/airootfs/etc/systemd/user/`), each with `Restart=always`, and Hyprland's start hook restarts them after it hands over the session's environment. `agentd` keeps its conversation and turn count in the runtime directory across a restart.
